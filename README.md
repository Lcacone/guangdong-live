# 粤现场 · 广东演出雷达

打开 http://127.0.0.1:8765 ，或双击「打开粤现场.cmd」。

## 已实现
- 广东21个地级市的演唱会、音乐节公开列表检测，逐条详情核验，演出时间、城市、场馆、海报和来源链接。
- 明确标注年份、日期的开票公告自动提取；没有可确认时间时显示「暂未查到」，不会将预售状态当作开票时间。
- 城市/类型筛选、搜索、排序、收藏、开票筛选、历史演出、更新日志。
- 每日北京时间08:00自动检查；启动时错过最近一次08:00则补查。失败保留既有数据，逐来源错误公开显示。
- 当前用户登录后自动启动，注册表 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 中的 YueLiveMonitor；删除该值可取消自启动。

## 运行范围
这是当前电脑上的可运行网站，不是公网域名。电脑须开机联网、服务运行才能采集；关闭浏览器不会停止服务。关机时无法更新。手机适配已验证，但默认仅监听本机127.0.0.1，其他设备不能直接访问。

目前接入大河票务公开演唱会、音乐节列表及详情页。仅覆盖该来源公开收录的广东条目，不代表全省所有演出。大麦接口存在访问验证，尚未接入。开票提取采用保守规则，无年份或非结构化公告可能无法识别；「暂未查到」不代表官方一定未公布。以主办方及官方售票平台公告为准。

首次成功扫描：2026-10-28，60条（58场演唱会、2场音乐节）。每次分页上限100页，超限会报告；访问失败/页面结构变化也会报告。

## 开发和迁移
Python 3.10+：`pip install -r requirements.txt`，运行 `python app.py`，或 `python app.py --refresh` 单次采集。SQLite数据库在 events.sqlite3，日志 server.log。launch.pyw 避免重复启动。当前启动CMD使用本机Python绝对路径，迁移后需调整。

公网长期运行需另行部署到持续在线服务器，使用生产WSGI服务、HTTPS与更新接口访问控制；当前本地版本未部署公网。
